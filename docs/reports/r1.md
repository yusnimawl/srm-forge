## Goal

Restyle the web app in a black, Scalar-style theme with no blue, and rename the label "EM-validated" to "2D-verified". Done when the owner signs off on screenshots of every page.

## What shipped

- Graphite theme: monochrome, white as the only accent, dark only, Geist and Geist Mono fonts. Tokens are in `web/src/index.css`.
- No blue in chrome or data. `web/src/lib/noBlue.test.ts` fails on blue colour literals, colour names and named Plotly scales.
- |B| in inferno through an explicit scale (`web/src/lib/inferno.ts`), because Plotly.js has no named Inferno.
- Series palette `LINE_COLORS` and `LINE_DASHES` with one dash pattern per case. One Plotly theme for every plot.
- Label "2D-verified" in the engine, API, UI and docs. No srmcore version bump, so 0.4.0 stays verified and cached maps stay valid.
- Status chips "2D-verified" and "assumes j_limit N A/mm²" ("not recorded" for older evaluations). `Evaluation.j_limit` runs end to end.
