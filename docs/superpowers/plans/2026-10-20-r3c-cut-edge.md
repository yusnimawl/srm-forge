# R3c Cut-Edge Build Factor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Multiply the hysteresis and excess iron loss of each element by an edge-band factor that depends on its distance to the cut edges and on the cutting process, and report the spread over processes as a one-sided uncertainty row.

**Architecture:** A pure numpy/scipy module `srmcore/post/cut_edge.py` finds the cut edges of the fixed iron mesh and the band fraction per element. `srmapp/losses.py` applies the multiplier in `stroke_losses` and computes the range from the linearity in a. A new `Requirements.cut_process` carries the choice; srmweb and `web/` show it.

**Tech Stack:** Python 3.12, numpy, scipy (`cKDTree`), pydantic; React/TypeScript (`web/`), vitest.

**Spec:** `docs/superpowers/specs/2026-10-20-r3c-cut-edge-design.md`

    for w in (5e-3, 10e-3, 30e-3):
        nodes, tris = _strip(w, 0.05, 0.1e-3)
        d = 0.5e-3
        area = _areas(nodes, tris)
        frac = band_fraction(nodes, tris, d)
        exact = (2 * d * (0.05 + w) - 4 * d * d) / (w * 0.05)
        assert np.sum(frac * area) / area.sum() == pytest.approx(exact, rel=0.01)

def test_strip_multiplier_follows_one_over_w():
    for name, p in CUT_PROCESSES.items():
        for w in (5e-3, 10e-3, 30e-3):
            length = 0.05
            nodes, tris = _strip(w, length, 0.1e-3)   # band edges fall on grid lines
            area = _areas(nodes, tris)
            m = edge_multiplier(band_fraction(nodes, tris, p.delta), p.a, p.delta)
            # 1 + a/w for the long edges, plus the two short ends minus the corner overlap
            ends = p.a / length - p.a * p.delta / (w * length) * 2
            assert np.sum(m * area) / area.sum() * B0 == pytest.approx(1 + p.a / w + ends, rel=0.01)

- [ ] **Step 3: Implement `src/srmcore/post/cut_edge.py`**

- `cut_edges`: sort each triangle's three node pairs, `np.unique(..., axis=0, return_counts=True)`, keep count 1.
- `band_fraction`: 6 interior sample points per triangle from the symmetric 6-point rule (barycentric (0.816847572980459, 0.091576213509771, 0.091576213509771) and permutations, (0.108103018168070, 0.445948490915965, 0.445948490915965) and permutations, weights 0.109951743655322 and 0.223381589678011). Weight each sample by its rule weight (the weights sum to 1). Distance to the nearest cut segment: a `cKDTree` on points along the cut segments spaced ≤ δ/8. Query the k = 8 nearest points, then take the exact point-to-segment distance over the segments those points belong to. Fraction = weighted share of samples with distance ≤ δ.
- Module docstring: the model, the 1/w law `a = 2 δ (K − 1)`, the source (Huynh et al. 2026, doi 10.1016/j.rineng.2026.112686), and a comment on each process row citing spec §5.
